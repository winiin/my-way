# Временный гостевой режим

Изменения в этой сборке:
1. При запуске автоматически создаётся локальный профиль `guest@myway.local`.
2. Экран входа/регистрации не показывается.
3. Данные гостя сохраняются в браузере через существующий механизм `localStorage`.
4. Для гостя отключены обращения к защищённым `/api/data` endpoints, поэтому `401 Unauthorized` от этих endpoints не блокирует приложение.
5. Действие «Выйти» временно показывает уведомление о гостевом режиме и не сбрасывает данные.

Ограничение: `localStorage` не синхронизируется между устройствами и браузерами. Для телефона и ноутбука с общими данными понадобится серверная гостевая сессия или полноценная авторизация с серверным хранилищем.
