# MY WAY — основной проект (гостевой режим)

Это объединённая рабочая основа на базе старого проекта `143-main`.
Сохранены исходный интерфейс, финансовые разделы и SQLite backend.
На этом этапе включён временный гостевой режим: регистрация и вход не требуются.

## Запуск в Windows / VS Code

1. Открой эту папку в VS Code.
2. Открой Terminal → New Terminal.
3. Выполни:

```powershell
npm install
npm start
```

Если PowerShell не распознаёт `npm`, используй:

```powershell
& "C:\Program Files\nodejs\npm.cmd" install
& "C:\Program Files\nodejs\npm.cmd" start
```

4. Открой в браузере `http://localhost:3000`.

## Гостевой режим

- Приложение автоматически открывает профиль «Гость».
- Регистрация и вход временно не используются.
- Данные сохраняются в `localStorage` браузера.
- Данные гостя доступны только в том же браузере и на том же устройстве.
- Очистка данных сайта / localStorage может удалить гостевые данные.
- Это режим для локальной разработки и проверки интерфейса, не для публичного размещения с реальными финансовыми данными.

## Что важно

- Не загружай `.env`, `myway.db`, `node_modules` и секреты в GitHub.
- `server.js` и `db.js` оставлены от старого проекта. Гостевой режим не отправляет запросы к защищённым API синхронизации.
- PostgreSQL-версия из более нового архива не копировалась поверх SQLite-проекта: у них разные схемы БД и backend-контракты. Её функции нужно переносить отдельно и проверять по одной, чтобы не сломать старый интерфейс.
- Перед публикацией в интернете нужно отдельно настроить серверное хранение данных, секреты, авторизацию и HTTPS.
